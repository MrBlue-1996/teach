# Hands-on Lab Projects

This directory contains practical, hands-on projects for students to build.

## Structure

Each project should include:

- `README.md` - Project overview and objectives
- `starter/` - Starter code and templates
- `solution/` - Reference solution
- `tests/` - Automated tests for validation
- `rubric.md` - Grading criteria

## Project Design Principles

1. **Solve First, Teach Second** - Projects should challenge students before providing guidance
2. **Device-Aware** - All projects must work on Chromebooks and low-resource devices
3. **Incremental** - Break complex projects into manageable steps
4. **Testable** - Include automated tests for validation
5. **Offline-Ready** - Projects should work without internet connection

## Example Projects

- **Personal Portfolio** - HTML/CSS website building
- **Todo App** - JavaScript state management
- **Quiz Game** - Event handling and DOM manipulation
- **Data Visualizer** - Working with data structures

## Testing Projects

Projects can be tested using:

- Automated test suites
- Manual validation checklists
- Peer review criteria
