## Key Findings (for Phase 1 planning)

1. **No Firebase** — auth is custom JWT (`jose`) + Supabase browser client. Any plan referencing Firebase must be updated.
2. **No PWA manifest** — `apps/web/public/` has no `manifest.json`. Chromebook installability = zero today.
3. **Two content formats** — `ContentPackManifest` (teaching packs) vs `ChallengeConfig` (kitchen packs). Different schemas, different validators.
4. **Dual migration systems** — Drizzle ORM (`pnpm db:migrate`) for API server + Supabase SQL migrations (`infrastructure/supabase/migrations/`) for Supabase-native features.
5. **Kitchen packs are static bundles** — registered in `apps/web/src/lib/kitchen-packs.ts` at build time. Runtime pack loading requires new infrastructure.
6. **6 UJ kitchen packs registered** — uj-fajita-rush, uj-enchilada-rush, uj-line-temps, uj-grill-setup, uj-queso-scale, uj-allergy-order.
