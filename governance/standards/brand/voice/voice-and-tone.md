# Top Shelf Service LLC™ — Voice & Tone

## Core Voice

**Direct, calm, and competent. No hype, no jargon, no gimmicks.**

We sound like a seasoned professional who's done this a hundred times.
We don't oversell. We don't use filler. We state what we do and let the work speak.

## Brand Personality

- **Confident** — we know the work is hard, and we've handled harder
- **Direct** — short sentences, active voice, no fluff
- **Honest** — no participation trophies, no sugar-coating
- **Calm** — never breathless, never desperate, never "excited to announce"
- **Competent** — precise language, respect for the user's intelligence

## Tagline

**"The hardest part is done for you."**

Use in hero sections, footers, and meta descriptions. Never alter the wording.

## Tone by Context

| Context        | Tone                   | Example                                                 |
| -------------- | ---------------------- | ------------------------------------------------------- |
| Landing page   | Confident, minimal     | "We handle the hard part."                              |
| Learning UI    | Calm, instructional    | "Type your command here."                               |
| Correct answer | Warm, brief            | "Correct."                                              |
| Wrong answer   | Neutral, forward       | "Not quite. Try again or see the explanation."          |
| Hint           | Guiding, not revealing | "Think about what wraps everything in an HTML file."    |
| Explanation    | Clear, educational     | "The `<html>` tag is the root element..."               |
| Error state    | Factual, helpful       | "Unable to load learning content."                      |
| Empty state    | Directional            | "Start your first course to see progress here."         |
| Loading        | Silent                 | Just a spinner — no "Please wait..." text               |
| Marketing      | Understated            | "Scheduling shouldn't be the hardest part of your day." |

## Writing Rules

1. **No hype words** — never "revolutionary", "game-changing", "exciting", "amazing"
2. **No exclamation marks** except on correct answer feedback
3. **No emoji** in the learning UI or marketing copy
4. **Use "you"** — speak directly to the user
5. **Present tense** — "Check Answer", not "Submit Your Answer"
6. **Verb-first buttons** — "Continue", "Try Again", "Need a hint?"
7. **Short labels** — max 3 words for buttons, max 6 for headings
8. **Monospace for code** — always `font-mono` for commands, tags, paths
9. **No jargon about internals** — never say "teaching mode", "trigger", "engine" in UI
10. **No stock language** — no "We're passionate about...", no "At [Company], we believe..."

## Do / Don't

| Do                                           | Don't                                             |
| -------------------------------------------- | ------------------------------------------------- |
| "We handle scheduling so you don't have to." | "We're excited to revolutionize scheduling!"      |
| "Your schedule is ready."                    | "Amazing news! Your schedule has been generated!" |
| "Correct."                                   | "Awesome job! You're killing it! 🎉"              |
| "Not quite. Try again."                      | "Oops! That's not right, but don't worry!"        |
| "Top Shelf Service LLC™"                     | "TopShelf", "Topshelf", "Top shelf"               |
