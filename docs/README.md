# TopShelf Teaching Documentation

This directory contains comprehensive documentation organized by topic.

## Structure

Documentation is organized in numbered folders (0-10) for progressive learning:

- **0-overview** - Project introduction and getting started
- **1-architecture** - System architecture and design
- **2-teaching-modes** - L0-L4 teaching modes explained
- **3-device-constraints** - Chromebook and device-aware features
- **4-pedagogy** - "Solve First, Teach Second" methodology
- **5-api** - API reference and endpoints
- **6-content-creation** - Creating domain packs
- **7-projects** - Hands-on lab guidelines
- **8-deployment** - Deployment and configuration
- **9-testing** - Testing strategies
- **10-contributing** - Contribution guidelines

Navigate to each folder for detailed documentation on that topic.
